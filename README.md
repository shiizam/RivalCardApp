# Project Title
[🚧 In Progress] - An iOS app for viewing cards & building decks for the card game "VTM: Rivals".

**Tech Stack:**  
- Programming Languages: Swift.
- Frameworks: SwiftData, SwiftUI.

### Description
A user-friendly deck building app for "VTM: Rivals" card game, developed using Swift, SwiftUI, & SwiftData. The app allows players to create, edit, & delete their decks with ease. 
With an intuitive interface, users can seamlessly add & remove cards from a current deck, search & view specific cards, or quickly build a new deck.  

### Features
- ✅ Deck Management: Build & manage multiple decks all of which are organized automatically based on the deck's vampire faction.
- ✅ Deck Builder: Don't stress about keeping track of how many cards you have while making a deck. The application will automatically track & update your card count for each type required to make
                    a game ready deck. 
- ✅ Account Creation: Create an account to manage your decks & view cards. After an initial sign-in, a token is saved to keep you signed in so you can avoid wasting time.
- ✅ Search & Filter: Quickly find the card you need by filtering by a specific faction or search based on any text that a card possesses. 
- 🚧 View All Cards (In Progress): New cards are still being added.
- 🚧 Change Themes (Future Plans): I plan to update the settings page to allow users to select from various color themes?
